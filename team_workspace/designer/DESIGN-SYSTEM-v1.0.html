Foundations

Pitch Rating Design System

A professional, cohesive interface built on the existing v3.17.0 tokens. Plain language, machine strings in small-print "technical details" only, provenance visible on every number, and an honest, unmissable "I don't know".

Non-negotiable principles (from A-02, P1, P3, M3, M7)

ℹ️
Plain languageEvery screen speaks in human terms. "Home win probability: 55.9%" — never "AI-predicted likelihood: 0.78". Machine strings live only in small-print technical-details.
ℹ️
Provenance small-printEvery probability and prediction shows Source · Window · n · Calibration. Small, dashed, always visible.
🕐
Honest refusal"I don't know" is a valid, shown output. The NO CALL state is visually distinct and unmissable; the balance panel always accompanies it (M7).
✕
No market dataNo odds, prices, spreads, lines, bookmakers, market implied probability, vig, juice, or margin in any visual element. Betting-style labels (e.g. "Double chance", "Draw no bet") are flagged for removal/relabel (see implementation spec).

Icons

Replace emoji (`🟢🟡🚫💾📄`) with a consistent 16px SVG sprite, colored by `currentColor`. This gives uniform weight, crisp rendering, and theme-following colors.

Status & action set

Green · has data Amber · partial Muted / no data Snapshot

All icons inherit color via `stroke="currentColor"` so they adapt to pill/alert context automatically. Spec: 16px grid, 1.75–2px stroke, rounded caps.

System

Accessibility & motion

  • Focus visible — 2px accent outline + 2px offset on every interactive element.
  • Color contrast — semantic and outcome colors meet AA on their surfaces in both themes.
  • Motion — 150–300ms transitions only (bars/metrers/theme fade). Respect prefers-reduced-motion.
  • Touch — interactive targets ≥40×40px on mobile.
  • Scales with font — rem/em units; layouts survive 200% zoom without horizontal scroll (except deliberate table scroll).
