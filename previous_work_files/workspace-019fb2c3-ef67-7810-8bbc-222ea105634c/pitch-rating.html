Step 1 — Generate a sync brief

Produces a complete statement of what the app holds and what it still needs: current model version, per-league “results through” dates, and the exact team spellings the parser accepts. Paste it into any AI with web access.

Step 2 — Paste the reply

Everything is checked before anything changes: header, league codes, date format, future dates, score ranges, team names, duplicates within the paste, results already applied, and a venue-plausibility test on every row. Nothing is applied until you review the report.

Why there is no “Fetch” button

The results sites that carry this data (football-data.co.uk and similar) send no access-control-allow-origin header, so a browser blocks any direct request from a local file. A working fetch button would need a server running in the middle — which is exactly the kind of third-party dependency we removed. Instead, paste results below: the app applies the identical learning step the trainer uses, so a pasted update and a full rebuild give the same ratings.

Manual entry (alternative to the sync brief)

One match per line. All of these work:
Arsenal 2-1 Chelsea  ·  Arsenal,2,1,Chelsea  ·  2026-08-15 Arsenal 2-1 Chelsea
Team names are matched loosely, and anything unrecognised is listed rather than skipped silently.

What this is

A Dixon–Coles rating model fitted to 153,058 league matches across 18 European leagues, 2003–2026. Every prediction below was generated using only matches played before it, so the validation is genuinely out-of-sample.

Limits

• Predicts outcomes, not value. Calibrated to reality; makes no profitability claim.
• No injuries, lineups, suspensions or fixture congestion — results only.
• Ratings are a snapshot from the build date and go stale; refresh periodically.
• 18 European leagues only.
• A home/away flip between evenly matched sides is undetectable by the model.
